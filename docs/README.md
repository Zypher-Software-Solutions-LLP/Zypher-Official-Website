# Zypher website documentation

This directory holds the decisions that keep the rebuild coherent across pages and providers.

- `architecture.md` describes the approved application boundaries.
- `seo.md` is the launch checklist for redirects, metadata, crawlability, and AI-readable content.
- `tracking.md` defines the initial consent and analytics event contract.
- `operations.md` records provider setup, environment separation, and production controls.

The current workspace intentionally contains no legacy URL export or Figma implementation files yet.
Those are inputs for the migration baseline and homepage section milestones.
